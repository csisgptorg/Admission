## 🔍 نحوه استفاده

### برای توسعه‌دهندگان جدید:
1. ابتدا `README.md` را مطالعه کنید تا با ساختار کلی آشنا شوید
2. سپس به `DETAILED_USE_CASES.md` مراجعه کنید تا جزئیات هر Use Case را ببینید
3. برای پیاده‌سازی ویژگی جدید، از الگوهای موجود الهام بگیرید

### برای مدیران پروژه:
1. `README.md` نمای کلی از قابلیت‌های سیستم را ارائه می‌دهد
2. آمار موجود در هر دو فایل می‌تواند برای برنامه‌ریزی مفید باشد

### برای تحلیلگران:
1. `DETAILED_USE_CASES.md` لیست کاملی از تمام قابلیت‌ها ارائه می‌دهد
2. دسته‌بندی‌ها به درک بهتر دامنه‌های کاری کمک می‌کند
