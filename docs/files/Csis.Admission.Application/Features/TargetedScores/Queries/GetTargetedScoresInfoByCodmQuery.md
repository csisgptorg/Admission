# GetTargetedScoresInfoByCodmQuery.cs

**مسیر**: `Csis.Admission.Application/Features/TargetedScores/Queries/GetTargetedScoresInfoByCodmQuery.cs`

## 1. هدف (Purpose)

این Query برای **دریافت امتیازات هدفمندی یارانه** دانشجو استفاده می‌شود.

### کاربرد اصلی:
- محاسبه امتیازات هدفمندی
- نمایش جزئیات امتیاز (تحصیلی، تدریس، تبلیغ، پژوهش، ایثارگری، حفظ قرآن)
- تعیین واجد شرایط بودن برای یارانه

---

## 2. ورودی (Input)

```csharp
public sealed record GetTargetedScoresInfoByCodmQuery(int Codm) : IRequest<TargetedScoreDto[]>;
```

| پارامتر | نوع | توضیحات |
|---------|-----|---------|
| `Codm` | `int` | کد ملی دانشجو |

---

## 3. خروجی (Output)

```csharp
TargetedScoreDto[] // آرایه امتیازات با ترتیب مشخص
```

1. شروط کلی

4. امتیاز تدریس جاری
5. امتیاز سابقه تدریس
6. امتیاز تبلیغ جاری
7. امتیاز سابقه تبلیغ

11. امتیاز حافظین
12. جمع امتیازات
13. ضرایب
14. امتیاز کل
